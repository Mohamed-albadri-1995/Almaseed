# فيديوهات تعليمية — أرشيف المسيد

سكربت يفتح الموقع الحقيقي ويسجّل **فيديو لكل تدفّق** مع مؤشّر مرئي وهالة ذهبية حول
الزر المطلوب وشريط تعليق عربي.

> يُشغَّل على **كمبيوتر** (ليس الجوّال). بيانات الدخول تُمرَّر كمتغيّرات بيئة عند التشغيل
> ولا تُحفظ في أي ملف.

## المتطلبات
- Node.js 18+ وat. اتصال بالإنترنت يصل إلى `almaseeed.com`.
- (لتحويل mp4) أداة `ffmpeg` مثبّتة.

## التشغيل
```bash
cd tutorials
npm install
npx playwright install chromium

BASE_URL=https://almaseeed.com \
REVIEWER1_EMAIL=... REVIEWER1_PASS=... \
REVIEWER2_EMAIL=... REVIEWER2_PASS=... \
CONTRIBUTOR_EMAIL=... CONTRIBUTOR_PASS=... \
DRY_RUN=1 \
node record.mjs
```
- الفيديوهات تظهر في `tutorials/out/*.webm`.
- تحويلها إلى mp4: `npm run mp4` (يتطلب ffmpeg).
- لتشغيل تدفّق واحد فقط: `node record.mjs 3-review-reject`.

## التشغيل من الجوّال (Termux) — وضع اللقطات ثم mp4
ويندوز القديم قد لا يصلح؛ Termux على أندرويد بديل عملي. الفيديو المباشر لا يعمل على
أندرويد، فنستخدم **وضع اللقطات** الذي يلتقط صورة لكل خطوة ثم يدمجها mp4 عبر ffmpeg:

```bash
# داخل Termux
pkg update -y
pkg install -y nodejs ffmpeg
# متصفّح النظام لأندرويد عبر مستودع tur:
pkg install -y tur-repo && pkg install -y chromium

cd tutorials
npm install playwright-core      # نواة فقط — بلا تنزيل متصفّح
export CHROMIUM_PATH="$(command -v chromium)"

MODE=shots BASE_URL=https://almaseeed.com \
REVIEWER1_EMAIL=... REVIEWER1_PASS=... \
REVIEWER2_EMAIL=... REVIEWER2_PASS=... \
CONTRIBUTOR_EMAIL=... CONTRIBUTOR_PASS=... \
node record.mjs
```
- الناتج: `out/<التدفّق>.mp4` (شرائح، ٢٫٥ث لكل خطوة) + اللقطات في `out/<التدفّق>/`.
- لتدفّق واحد: `MODE=shots node record.mjs 3-review-reject`.
- إن لم يتوفّر `chromium` في Termux، ثبّت متصفّحًا وضع مساره في `CHROMIUM_PATH`.

## الأوضاع
- `DRY_RUN=1` (الافتراضي): **آمن على الإنتاج** — يقف عند الأزرار التي تغيّر البيانات فعليًّا
  (نشر/رفض/حذف/إرسال) ويُبرزها فقط دون الضغط. مناسب لتصوير الخطوات دون تعديل بيانات الموقع.
- `DRY_RUN=0`: **ينفّذ فعلًا**. استخدمه فقط مع **حسابات ومواد تجريبية**، لأنه سيغيّر بيانات
  حقيقية (ينشر/يرفض/يحذف).

## التدفّقات ومتطلباتها
| التدفّق | المحتوى | يحتاج |
|---|---|---|
| 1-register | تسجيل حساب جديد | — |
| 2-login | تسجيل الدخول | حساب مساهم |
| 3-upload | رفع مادة من الرئيسية + ملء الفورم | حساب مساهم + `SAMPLE_FILE` (افتراضي `sample.mp3`) |
| 4-track-status | متابعة الحالة + الإشعارات (قبول/رفض/تعديل) | حساب مساهم له مواد مُرسَلة |
| 5-review-all | المراجعة: كل الخيارات + التعديل بنفسك | حساب مراجع + مادة «قيد المراجعة» |
| 6-two-reject | الرفض بمراجعَين (الرافض + المُثنّي) | حسابا مراجعَين + مادة «قيد المراجعة» |
| 7-delete-request | طلب حذف (تصويت القسم) | حساب مراجع + مادة منشورة |
| 8-delete-vote | المشاركة في تصويت الحذف | حساب مراجع ثانٍ + تصويت مفتوح |

## ملاحظات
- التسعة الأزرار مطابقة لنصوص الموقع الفعلية («موافقة ونشر»، «رفض المادة»، «طلب تعديل»،
  «تأكيد القرار»، «فتح تصويت الحذف»، «أوافق على الحذف»…).
- إن تغيّر نص زرٍّ مستقبلًا، عدّل الاسم في `record.mjs`.
- لا تُرفع بيانات الدخول ولا الفيديوهات إلى المستودع (مجلد `out/` مُتجاهَل).
