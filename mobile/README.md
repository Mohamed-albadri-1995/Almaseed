# تطبيق أرشيف المسيد (Expo / React Native)

تطبيق بسيط لأرشيف المسيد فيه ثلاثة خيارات:

1. **الاستماع والتنزيل** — مشغّل ميديا أصلي: تصفّح الأقسام، استمع، ونزّل
   الملفات (بما فيها المقروءات) بخيارين: **حفظ داخل التطبيق** و**تنزيل إلى الجهاز**.
2. **دخول كمشرف نظام** — يفتح لوحة الإشراف داخل التطبيق.
3. **دخول كمساهم** — يفتح حسابك لإرسال المواد.

يتصل التطبيق بخادم الموقع عبر `config.js`.

## التشغيل للتجربة

المتطلبات: Node.js، وتطبيق **Expo Go** على هاتفك (من Google Play / App Store).

```bash
cd mobile
npm install          # أو: npx expo install
npx expo start
```

- امسح رمز QR الظاهر بتطبيق **Expo Go** (أندرويد) أو الكاميرا (آيفون).
- سيفتح التطبيق مباشرة على هاتفك.

## تغيير عنوان الخادم

إن انتقل الموقع إلى نطاق مخصّص (دومين)، غيّر سطراً واحداً في `config.js`:

```js
export const API_BASE = 'https://your-new-domain';
```

## بناء نسخة قابلة للنشر (لاحقاً)

لإصدار ملف تثبيت (APK/AAB لأندرويد أو للـ App Store):

```bash
npm install -g eas-cli
eas login
eas build -p android    # أو: -p ios
```

يتطلب النشر على المتجرين حساب مطوّر (Google Play لمرة واحدة، Apple سنوي).
